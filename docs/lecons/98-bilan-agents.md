# Leçon 98 — Bilan : ajouter des agents

> **Commit** : `docs: README, sécurité, feuille de route et cours (leçons 94 à 98)`
> **Phase** : le bureau des agents

## 1. Ce qu'on a ajouté

- Dans l'admin, **« Nouvel agent »** : un nom, ce qu'il fait, ce qu'il peut faire (parcourir, lire, écrire avec votre accord), une consigne. On le modifie, on le retire.
- Au bureau, on **choisit l'agent** d'une question ; il s'installe au bureau de l'analyste, avec le visage recruté pour lui.
- La page Agents a perdu son tableau redondant et ses explications : des cartes courtes, des pastilles.

## 2. Ce qui n'a pas bougé

L'accord humain avant d'écrire, les garde-fous ajoutés à chaque consigne, la liste fermée des outils. Une revue automatique a même trouvé un contournement (une relance qui réutilisait un agent retiré) : corrigé le jour même.
